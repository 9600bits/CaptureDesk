CaptureDesk 0.5 Windows x64 安装版。

- 提供截图、原选区标注、贴图、长截图、MP4 / GIF 录制、文字识别和表格识别。
- 移除公式识别及 Python / 模型依赖。
- MiSans 字体、森林绿浅色 / 深色界面及新应用图标。
- 安装包自带 .NET 运行环境，无需另外下载安装；不需要账号。
- 重复启动会提示并唤醒已有实例；安装和卸载会在 CaptureDesk 运行时要求先退出。
- 修复 JPEG / CSV 保存格式与扩展名不一致，并为配置文件增加原子保存和备份恢复。

系统要求：Windows 10 22H2 或 Windows 11 x64。OCR 需要对应的 Windows 语言包。

下载 `CaptureDesk-0.5-win-x64-setup.exe` 安装。`SHA256SUMS.txt` 用于核对文件完整性。安装包未代码签名，Windows 可能显示未知发布者提示。

安装包大小：64,271,059 字节（约 61.3 MiB）。已在当前 Windows 电脑验证安装文件一致性、安装后应用回归检查、运行中升级 / 卸载保护及正常卸载；卸载保留个人设置和额外文件。

已知限制：表格识别的低清文字、短数字可能遗漏，需要对照原图核对；录制不含音频，MP4 编码依赖 Windows 内置 H.264 编码器。
