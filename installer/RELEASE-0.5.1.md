CaptureDesk 0.5.1 Windows x64 安装版。

- 提供截图、原选区标注、贴图、长截图、MP4 / GIF 录制和文字识别。
- 移除不可用的表格识别功能。
- 修复录屏结束后关闭窗口时可能出现的截图失败提示。
- 安装包自带 .NET 运行环境，无需另外下载安装；不需要账号。

系统要求：Windows 10 22H2 或 Windows 11 x64。OCR 需要对应的 Windows 语言包。

下载 `CaptureDesk-0.5.1-win-x64-setup.exe` 安装。`SHA256SUMS.txt` 用于核对文件完整性。安装包未代码签名，Windows 可能显示未知发布者提示。

已知限制：文字识别的低清文字、短数字可能遗漏，需要对照原图核对；录制不含音频，MP4 编码依赖 Windows 内置 H.264 编码器。
