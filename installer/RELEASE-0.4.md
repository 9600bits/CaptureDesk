CaptureDesk 0.4 Windows x64 安装版。

- 提供截图、原选区标注、贴图、长截图、GIF 录制、文字识别和表格识别。
- 移除公式识别及 Python / 模型依赖。
- MiSans 字体、森林绿浅色 / 深色界面及新应用图标。
- 安装包自带 .NET 运行环境，无需另外下载安装；不需要账号。

系统要求：Windows 10 22H2 或 Windows 11 x64。OCR 需要对应的 Windows 语言包。

下载 `CaptureDesk-0.4-win-x64-setup.exe` 安装。`SHA256SUMS.txt` 用于核对文件完整性。安装包未代码签名，Windows 可能显示未知发布者提示。

已知限制：表格识别的低清文字、短数字可能遗漏，需要对照原图核对；截图历史仅在当前会话保留。录制当前支持 GIF，不含音频。
